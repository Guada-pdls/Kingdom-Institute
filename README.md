# Kingdom Institute

Welcome to the Kingdom Institute project! This web application is designed to provide English students with information about our academy classes, the latest news, a convenient contact form, and access to level placement tests.

## Table of Contents

* [Features](#features)
* [Requirements](#requirements)
* [Installation](#installation)
* [Usage](#usage)


## Features

* **Informative Academy Class Listings:**  Browse detailed information about our available English language courses.
* **Latest News and Announcements:** Stay updated with the latest news from the Kingdom Institute.
* **Contact Form:** Easily get in touch with us through a convenient contact form.
* **Placement Test:** Take a placement test to determine your appropriate English language level.
* **Test CRUD**  (For Administrators)  Manage and maintain news (in progress).


## Requirements

* **Node.js:**  Ensure you have a compatible version of Node.js installed on your system.  [Download Node.js](https://nodejs.org/)
* **npm or yarn:** A package manager is required to install project dependencies.  npm is typically included with Node.js, but yarn can also be used.

## Installation

1. Clone the repository: `git clone https://github.com/Guada-pdls/Kingdom-Institute`
2. Navigate to the project directory: `cd Kingdom-Institute`
3. Install dependencies: `npm install` (or `yarn install`)
4. Start the development server: `npm start` (Further instructions on starting the development server may be needed based on the project setup)

## Usage

This application provides English language students with resources to learn more about our academy and assess their English proficiency.  Use the intuitive interface to explore class information, read the latest news, contact us, and take a placement test.  For administrators, the Test CRUD functionality allows for management of available news.
